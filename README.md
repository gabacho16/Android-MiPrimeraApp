ANDROID MI PRIMERA APP

DESCRIPCIÓN

Aplicación móvil desarrollada en Android Studio utilizando Kotlin y Jetpack Compose. 
El proyecto cuenta con una pantalla de inicio de sesión y una pantalla de registro, 
permitiendo al usuario navegar entre ambas interfaces.

INTEGRANTES:
-JOSÉ GABRIEL LEY MUÑOZ

REQUISITOS:

Para ejecutar el proyecto se necesita:

-Android Studio instalado.
-JDK compatible con la versión del proyecto.
-Un emulador Android o un dispositivo físico.

INSTRUCCIONES PARA EJECUTAR EL PROYECTO:

-Descargar o clonar este repositorio.
-Abrir el proyecto desde Android Studio.
-Seleccionar un emulador o conectar un dispositivo Android.
-Ejecutar el proyecto presionando el botón Run ▶.
-Esperar a que la aplicación se instale y se abra en el dispositivo.
